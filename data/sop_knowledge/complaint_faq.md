# 投诉类常见问题SOP

> 本文档适用于教育培训机构"二讲老师"在家长答疑场景下的投诉类问题标准回复参考。处理投诉时务必遵循"先倾听、再共情、后解决、必跟进"的原则。二讲老师需根据实际情况灵活调整话术，保持专业、真诚、有温度的沟通风格。

---

## Q1: 老师态度不好，对孩子不耐烦怎么办？

**分类：** 投诉类
**适用场景：** 家长反映任课老师对孩子态度不好、缺乏耐心
**标准回复要点：**
1. 严肃对待，认真倾听家长的具体描述
2. 真诚致歉，不推脱、不辩解
3. 详细了解事情经过（时间、具体言行、在场人员）
4. 表示会立即调查核实
5. 承诺在[X时间]内给家长反馈
6. 提出初步的解决方案，让家长感到被重视

**话术模板：**
"XX妈妈您好，听到您说这个情况我非常重视，也非常抱歉让您和孩子有这样的体验。您能具体跟我说一下是什么时候发生的吗？老师当时说了什么或做了什么让XX不舒服？[认真倾听记录]好的，我了解清楚了。请您放心，我会立即跟[相关老师/教学主管]沟通核实这个情况。我们一直要求老师对每一个孩子都要耐心负责，如果确实存在态度问题，我们一定会严肃处理。我会在[具体时间，如明天中午前]给您一个明确的反馈和处理结果。在此之前，我会先跟XX聊一聊，安抚一下孩子的情绪。再次为这个情况向您道歉，感谢您及时反馈。"

## Q2: 教学效果不满意，感觉孩子没进步怎么办？

**分类：** 投诉类
**适用场景：** 家长对教学效果不满意，质疑课程价值
**标准回复要点：**
1. 认真对待家长的反馈，不回避问题
2. 用客观数据展示孩子的学习轨迹（入学水平 vs 当前水平）
3. 分析效果不理想的具体原因
4. 承认可能存在的不足，表达改进意愿
5. 提出具体的改进方案
6. 设定明确的阶段性目标和评估节点

**话术模板：**
"XX爸爸您好，我非常理解您的心情，您花了时间和精力让孩子来学习，当然希望看到效果。您说效果不满意，我特别重视这个反馈。我先跟您看一下XX这段时间的学习数据：入学时XX的[具体指标]是[X]，现在是[X]，变化是[描述]。我承认，这个进步幅度确实没有达到我们的预期目标。我分析了一下原因：一是[原因1]，二是[原因2]，其中[承认不足的部分]确实是我们需要改进的。接下来我会做以下调整：[具体改进方案]。同时，我设定了一个[X周]的提升目标：[具体可衡量目标]。到[时间]我们做一次正式评估，如果效果还是不理想，我们再讨论进一步的方案，包括[说明备选方案]。您看这样处理可以吗？"

## Q3: 课堂纪律不好，影响孩子学习怎么办？

**分类：** 投诉类
**适用场景：** 家长反映课堂纪律差、其他学生干扰自己孩子学习
**标准回复要点：**
1. 认可家长的担忧，表示理解
2. 了解具体情况（是偶尔还是经常、哪些学生、什么行为）
3. 说明机构对课堂管理的标准和措施
4. 承诺加强课堂管理
5. 提出针对自己孩子的保障措施
6. 持续跟进，反馈改善情况

**话术模板：**
"XX妈妈您好，课堂纪律问题确实会影响学习效果，您的担心我完全理解。您能跟我说一下具体是什么情况吗？是某些同学比较吵闹，还是整体课堂秩序不太好？[了解详情]好的，我了解了。关于课堂管理，我们是有明确标准的：课堂人数控制在[X人]以内，老师有责任维持好秩序。如果确实存在纪律问题，我会做以下几件事：一是跟任课老师沟通，加强课堂管理；二是如果是个别同学的问题，我会跟对方家长沟通；三是给XX调一个相对安静的座位。我会在[时间]跟您反馈改善情况。如果持续没有改善，我们也可以讨论是否需要给XX换一个班级。"

## Q4: 作业批改不及时，孩子不知道对错怎么办？

**分类：** 投诉类
**适用场景：** 家长反映作业批改速度慢，影响学习反馈
**标准回复要点：**
1. 为批改不及时致歉
2. 了解具体是哪些作业没有及时批改
3. 立即处理积压的作业批改
4. 说明正常的批改周期和时效标准
5. 提出改进措施，避免再次发生
6. 建立家长可追踪的反馈机制

**话术模板：**
"XX爸爸您好，非常抱歉作业批改没有及时跟上，这确实不应该，影响到了XX的学习反馈。我马上核实一下XX哪些作业还没有批改，今天之内一定批完发给您。关于作业批改，我们的标准是[如每次课后48小时内完成]，这次确实没有达到标准，我会跟相关老师沟通，确保后续不再出现这种情况。为了方便您追踪，以后每次作业批改完成后我都会在群里通知您。同时，我也会建立一个作业完成和批改的记录表，定期同步给您。再次为这次的情况道歉，以后我会更加注意。"

## Q5: 孩子在学校被老师批评了，心里很难受怎么办？

**分类：** 投诉类
**适用场景：** 家长反映孩子被老师批评后情绪低落，家长心疼不满
**标准回复要点：**
1. 首先关注孩子的情绪状态，表达关心
2. 了解批评的具体情况和原因
3. 不急于站队，客观了解事情全貌
4. 如果批评方式不当，真诚道歉并承诺改进
5. 如果批评有合理性，温和地向家长解释并给出引导建议
6. 跟进孩子的情绪恢复情况

**话术模板：**
"XX妈妈您好，听到XX心里难受我特别心疼，孩子的心情是第一位的。您能跟我说一下XX跟您说了什么吗？老师是因为什么事情批评了XX？[倾听了解]我了解了。首先，无论原因是什么，如果老师的批评方式让XX感到不舒服，我代表学校向XX道歉，孩子来学习应该是开心的事情。我会跟这位老师沟通，了解当时的情况。如果是批评方式的问题，我们会要求老师调整方式，更加注意孩子的感受。同时，我想跟XX单独聊一聊，安抚一下孩子的情绪。您在家也可以[具体建议，如倾听孩子的感受、告诉孩子老师批评不等于不喜欢TA]。我明天跟您反馈沟通结果。"

## Q6: 排课时间不合理，跟学校时间冲突怎么办？

**分类：** 投诉类
**适用场景：** 家长反映课程安排时间不方便，与学校或其他安排冲突
**标准回复要点：**
1. 理解家长的困扰，表示歉意
2. 了解具体的冲突情况
3. 查看可替代的上课时段
4. 提供多个解决方案供家长选择
5. 如果确实无法调整，说明原因并给出替代方案
6. 记录需求，反馈给排课部门优化

**话术模板：**
"XX爸爸您好，排课时间冲突确实很麻烦，我理解您的困扰。您说的是[具体时间]的课跟[具体安排]冲突了对吗？我帮您看一下有没有其他时段可以调。[查看可选时段]目前可选的替代时段有：[列出2-3个选项]。如果您觉得这些时段都不太方便，我也可以帮您申请[其他方案，如调到其他校区/安排线上课/合并课时调整]。另外，我会把这个排课冲突的问题反馈给教务部门，看看后续能不能优化排课安排，尽量避免类似情况。您先看看哪个方案比较合适，我帮您处理。"

## Q7: 教材有错误/质量不好，影响学习怎么办？

**分类：** 投诉类
**适用场景：** 家长反映教材内容有误或印刷质量有问题
**标准回复要点：**
1. 感谢家长指出问题，表示重视
2. 了解具体是哪本教材、哪个页面、什么问题
3. 如果是内容错误，立即核实并发布勘误
4. 如果是印刷质量问题，安排更换
5. 说明问题产生的原因（不推卸责任）
6. 建立教材问题反馈机制

**话术模板：**
"XX妈妈您好，非常感谢您指出这个问题，教材质量直接影响学习体验，我们非常重视。您说的是[具体教材名称]的[具体问题]对吗？能不能拍个照片发给我，我马上核实。[核实后]确认了，确实是[描述问题]。如果是内容错误，我会立即通知教研部门，发布勘误说明，并在课堂上跟孩子们讲清楚正确的内容。如果是印刷质量问题，我马上安排更换一本新的给XX，[具体方式，如下次上课带来/邮寄到家]。非常抱歉给您和XX带来不便，我们会加强教材的审核和质量把控。以后如果发现任何教材问题，随时告诉我。"

## Q8: 孩子跟其他同学有矛盾，不想跟TA在一个班怎么办？

**分类：** 投诉类
**适用场景：** 家长反映孩子与班级同学发生矛盾，影响上课体验
**标准回复要点：**
1. 重视孩子的社交感受，表示理解
2. 了解矛盾的具体情况和严重程度
3. 不偏袒任何一方，客观了解事情经过
4. 提出解决方案（调解/调座位/换班）
5. 关注孩子在课堂上的情绪变化
6. 持续跟进矛盾是否解决

**话术模板：**
"XX爸爸您好，孩子之间有矛盾确实会影响上课心情，我完全理解。您能跟我说一下大概是什么情况吗？[倾听了解]好的，我了解了。这个问题我会这样处理：首先，我会分别跟两个孩子聊一聊，了解各自的想法，尝试做一个简单的调解。其次，在调解期间，我可以先把XX的座位调开，避免两个孩子直接接触。如果调解后矛盾仍然存在，影响了XX的正常上课，我们可以讨论是否需要调班。在这个过程中，我会持续关注XX在课堂上的情绪状态，有任何情况及时跟您沟通。您在家也可以多跟XX聊聊，了解孩子的感受。"

## Q9: 退费金额不对/退费太慢，怎么处理？

**分类：** 投诉类
**适用场景：** 家长对退费金额或退费速度不满
**标准回复要点：**
1. 重视家长的诉求，不推诿
2. 详细了解家长的退费诉求和不满点
3. 核实退费金额的计算是否正确
4. 如果计算有误，立即纠正并道歉
5. 如果计算无误，耐心解释计算方式
6. 加快退费流程，给出明确的时间节点

**话术模板：**
"XX妈妈您好，关于退费的问题我非常重视。您对退费金额有疑问是吗？我帮您重新核算一下。[核算后]我跟您详细说明一下退费的计算方式：您总共购买的是[X课时]，费用[X元]，已经上了[X课时]，按[原价/协议价]扣除[X元]，教材费[X元，如适用]，手续费[X元，如适用]，应退金额是[X元]。如果您觉得计算有问题，我可以把详细的费用明细发给您核对。关于退费速度，我理解您着急，我这边帮您加急处理，正常流程是[X个工作日]，我帮您催一下，尽量在[X个工作日]内到账。如果到[具体时间]还没有收到退款，您直接联系我，我帮您跟进。"

## Q10: 投诉了但没有得到解决，怎么办？

**分类：** 投诉类
**适用场景：** 家长之前反馈过问题但未得到有效解决，情绪升级
**标准回复要点：**
1. 为之前的处理不力真诚道歉
2. 重新了解问题，确认之前的投诉内容和处理情况
3. 承诺升级处理，由更高层级介入
4. 给出明确的解决时间节点
5. 指定专人负责跟进
6. 建立定期反馈机制直到问题解决

**话术模板：**
"XX爸爸您好，首先我要向您真诚地道歉，您之前反馈的问题没有得到及时有效的解决，这是我们的工作失误，我非常理解您的不满。您之前反映的问题是[复述问题]，对吗？当时给您的处理方案是[描述之前的处理]，但您觉得[了解不满意的原因]。这次我会升级处理：一是我会直接跟[教学主管/校区负责人]汇报这个情况，由更高层级来介入；二是我会作为您的专属对接人，全程跟进这个问题；三是我在[具体时间]前一定给您一个满意的解决方案。在此期间，您有任何不满或新的反馈，随时直接联系我。我保证这次一定给您一个满意的结果。"

## Q11: 对二讲老师的服务不满意，想换个老师对接怎么办？

**分类：** 投诉类
**适用场景：** 家长对负责对接的二讲老师服务不满意，要求更换
**标准回复要点：**
1. 虚心接受家长的反馈，不辩解
2. 了解不满意的具体方面
3. 如果是沟通方式问题，表达改进意愿
4. 如果家长坚持更换，尊重家长选择
5. 说明更换流程和交接安排
6. 确保交接期间服务不中断

**话术模板：**
"XX妈妈您好，听到您对我的服务不满意，我心里挺难过的，但我也非常感谢您愿意直接告诉我。您能跟我说一下主要是哪些方面让您不满意吗？[倾听了解]我了解了。首先，如果是我服务不到位的地方，我真诚向您道歉。如果您愿意给我一次改进的机会，我会在[具体方面]做出调整。当然，如果您觉得还是需要更换对接老师，我完全尊重您的选择。我会帮您安排交接，确保您和孩子的一切信息完整地转交给新的对接老师，不会影响XX的学习。交接期间我会和新老师一起跟您沟通，确保平稳过渡。无论结果如何，我都感谢您这段时间的信任。"

## Q12: 觉得机构收费不透明，有隐形消费怎么办？

**分类：** 投诉类
**适用场景：** 家长质疑收费透明度，认为存在隐形消费
**标准回复要点：**
1. 重视家长的疑虑，表示理解
2. 了解家长认为哪些费用不透明
3. 逐条解释相关费用的收费标准和依据
4. 如果确实存在收费说明不清的情况，真诚道歉并改进
5. 提供完整的费用清单和收费说明
6. 承诺后续收费更加透明公开

**话术模板：**
"XX爸爸您好，收费透明是我们非常重视的原则，您提出这个疑虑我完全理解，也特别感谢您直接跟我说。您觉得哪些费用不够透明呢？[了解具体疑虑]好的，我逐一跟您说明：[逐条解释各项费用]。如果您觉得我们之前的收费说明确实不够清楚，我代表机构向您道歉。我这边整理了一份完整的费用清单和收费标准说明，发给您看一下[发送文件]。以后涉及到任何费用，我都会提前跟您明确说明，绝不会有未经沟通的收费。如果您还有任何费用方面的疑问，随时问我，我一定解释清楚。"
