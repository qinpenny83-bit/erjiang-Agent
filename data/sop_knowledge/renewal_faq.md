# 续费类常见问题SOP

> 本文档适用于教育培训机构"二讲老师"在家长答疑场景下的续费类问题标准回复参考。二讲老师需根据实际情况灵活调整话术，保持专业、真诚、有温度的沟通风格。

---

## Q1: 续费有优惠活动吗？现在报名最划算吗？

**分类：** 续费类
**适用场景：** 家长咨询续费优惠政策和最佳报名时机
**标准回复要点：**
1. 感谢家长的续费意向，表达对孩子学习的重视
2. 介绍当前的优惠活动内容和力度
3. 对比日常价格和优惠价格的差异，让家长感受到实惠
4. 说明优惠活动的截止时间，制造合理紧迫感
5. 介绍不同套餐的性价比
6. 主动提出帮家长计算最优方案

**话术模板：**
"XX妈妈您好，特别感谢您一直以来对我们的信任！关于续费优惠，目前我们正好有[X活动名称]的活动，优惠力度确实很不错。给您算一下：平时[X课时]的价格是[X元]，现在活动期间是[X元]，直接省了[X元]，相当于打了[X折]。而且现在续费还额外赠送[赠品/额外课时/服务]。这个活动到[X月X日]就截止了，之后就会恢复原价。根据XX目前的学习进度，我建议选择[推荐套餐]，这样[说明理由，如可以覆盖到下学期末/性价比最高]。我帮您详细算一下各个方案的费用对比，您看一下[发送对比表格]。"

## Q2: 你们的课程套餐有哪些？哪个适合我家孩子？

**分类：** 续费类
**适用场景：** 家长咨询不同课程套餐的区别和选择建议
**标准回复要点：**
1. 介绍所有可选的套餐类型和价格
2. 用表格或列表清晰对比各套餐差异
3. 根据孩子的学习情况和需求给出专业推荐
4. 说明各套餐包含的具体服务内容
5. 分析各套餐的性价比
6. 尊重家长的选择，不强制推销

**话术模板：**
"XX爸爸您好，我给您详细介绍一下我们的课程套餐。目前有以下几个选择：一是[基础套餐]，[X课时]，价格[X元]，适合[适用场景]；二是[标准套餐]，[X课时]，价格[X元]，包含[额外服务]，适合[适用场景]；三是[尊享套餐]，[X课时]，价格[X元]，包含[全部服务]，适合[适用场景]。根据XX目前的学习情况——[描述孩子情况，如每周上X次课、需要课后辅导等]，我个人比较推荐[具体套餐]，因为[推荐理由]。当然，最终还是要看您的需求和预算，我把各套餐的详细对比发给您[发送对比]，您考虑一下。"

## Q3: 如果中途不想学了，可以退费吗？

**分类：** 续费类
**适用场景：** 家长在续费前咨询退费政策，需要安全感
**标准回复要点：**
1. 坦诚说明退费政策，不回避
2. 解释退费的具体计算方式
3. 说明退费的申请流程和周期
4. 告知退费可能涉及的扣除项
5. 表达信心，说明大部分学员都坚持了下来
6. 引导家长关注当前的学习效果而非退费

**话术模板：**
"XX妈妈您好，这个问题问得很好，我理解您想提前了解清楚。我们的退费政策是这样的：如果中途需要退费，已经上过的课时按[原价/优惠价]扣除，剩余课时费用在[X个工作日]内退还到您的[支付方式]。需要扣除的费用包括[说明扣除项，如已上课时费、教材费等]。不过我想跟您说一下，XX这段时间的学习其实进步挺明显的[列举具体进步]，而且接下来的课程安排也是针对XX的情况精心设计的。当然，退费政策是您的权益，了解清楚是应该的。如果您后续有任何顾虑，随时跟我沟通，我们一起解决。"

## Q4: 可以先暂停课程，以后再继续吗？

**分类：** 续费类
**适用场景：** 家长因特殊原因需要暂停课程一段时间
**标准回复要点：**
1. 了解暂停的原因和预计时长
2. 说明课程暂停/休学的政策和规则
3. 告知暂停期间课时如何处理
4. 说明恢复课程时的安排
5. 提醒暂停期限（如有）
6. 表达理解和支持

**话术模板：**
"XX爸爸您好，理解您的情况。课程暂停我们是可以办理的，叫做'休学/暂停'手续。具体来说：您需要暂停多久呢？[了解需求]好的，如果暂停时间在[X个月]以内，课时会自动冻结，恢复上课后继续使用剩余课时，不影响有效期。如果暂停超过[X个月]，可能需要[说明特殊情况处理]。办理的话，您只需要[说明流程，如填写一份暂停申请表]，我帮您提交。暂停期间，我也会不定期给XX发一些学习资料，让孩子保持学习状态。等您准备好恢复上课时，提前[X天]告诉我，我帮您安排。"

## Q5: 孩子想试试其他科目，可以试听吗？

**分类：** 续费类
**适用场景：** 家长或孩子想体验其他科目/课程，咨询试听安排
**标准回复要点：**
1. 欢迎孩子拓展学习兴趣
2. 介绍可试听的科目和课程
3. 说明试听的安排方式（免费/付费、时长）
4. 帮助预约合适的试听时间
5. 说明试听后的报名流程
6. 根据孩子特点给出科目选择建议

**话术模板：**
"XX妈妈您好，当然可以试听！拓展学习面是好事。我们目前开设的科目有[列出科目]，每个科目都可以安排试听。试听课一般是[X分钟]，可以免费体验[X]次。根据XX目前的情况，我觉得[推荐科目]可能比较适合XX，因为[推荐理由，如和当前科目有互补性/孩子有这方面的潜质]。试听时间可以安排在[列出可选时间]，您看哪个方便？试听后如果XX喜欢，我可以帮您办理报名，如果已经在读学员报第二科，还可以享受[优惠信息]。"

## Q6: 老带新有优惠吗？介绍朋友来报名有什么好处？

**分类：** 续费类
**适用场景：** 老学员家长咨询转介绍/老带新优惠政策
**标准回复要点：**
1. 感谢家长的推荐意愿
2. 介绍老带新活动的具体内容和奖励
3. 说明双方都能享受的优惠
4. 解释推荐流程和奖励发放方式
5. 说明活动是否有名额或时间限制
6. 表达对家长信任的感谢

**话术模板：**
"XX爸爸您好，特别感谢您愿意推荐朋友来！我们的老带新活动是这样的：您每成功推荐一位新学员报名，双方都可以获得[具体奖励，如各赠送X课时/X元优惠券/学习礼包]。奖励会在新学员完成报名并上课[X次]后发放到您的账户。推荐流程很简单：您让朋友报名时提到XX的名字，或者直接把我的微信推给TA，我来对接就行。目前这个活动没有名额限制，[时间限制说明]。再次感谢您对我们的认可和推荐！"

---

## Q7: 两个孩子一起报名有优惠吗？

**分类：** 续费类
**适用场景：** 同一家庭有多个孩子或亲友孩子一起报名咨询优惠
**标准回复要点：**
1. 介绍多学员报名的优惠政策
2. 说明优惠的具体力度和适用条件
3. 对比单报和合报的价格差异
4. 介绍兄弟姐妹各自的学习安排
5. 说明是否可以共享课时
6. 主动帮家长计算最优方案

**话术模板：**
"XX妈妈您好，两个孩子一起报名是有优惠的！我们目前有'手足同行'活动：两个孩子同时报名，第二个人可以享受[X折优惠]/每人各赠送[X课时]。我帮您算一下：如果分开报的话，两个孩子总共需要[X元]，一起报的话是[X元，省了X元]。两个孩子可以上同一个班级（如果水平接近的话），也可以分别安排适合各自水平的班级。课时是各自独立的，不能共享。您要不要考虑一下？我帮您把两个孩子的情况都评估一下，给出最合适的方案。"

## Q8: 续费的最佳时间是什么时候？快到期了怎么办？

**分类：** 续费类
**适用场景：** 家长咨询续费时机，或课时即将到期需要提醒
**标准回复要点：**
1. 告知当前剩余课时情况
2. 说明续费的最佳时间窗口
3. 解释提前续费的好处（优惠、排课优先等）
4. 提醒课时到期后的影响
5. 主动推荐适合的续费方案
6. 协助办理续费手续

**话术模板：**
"XX妈妈您好，我帮您查了一下，XX目前的剩余课时还有[X课时]，按照目前的上课频率（每周[X]次），大约可以上到[具体日期]。建议您在剩余[X课时/约X周]的时候就开始考虑续费，这样有几个好处：一是可以享受当前的优惠活动，二是可以优先选择心仪的上课时段，三是不会出现课时用完断课的情况。如果您现在续费的话，刚好赶上[当前优惠活动]，比较划算。我帮您把续费方案整理一下发给您，您看看哪个合适？"

## Q9: 课程有效期是多久？过期了怎么办？

**分类：** 续费类
**适用场景：** 家长咨询课程有效期的计算方式和过期处理
**标准回复要点：**
1. 说明课程有效期的计算方式
2. 告知当前课程的有效期截止日期
3. 说明有效期内的灵活安排方式
4. 解释过期后的处理政策
5. 提供延长有效期的条件（如续费可延期）
6. 建议家长合理安排上课频率

**话术模板：**
"XX爸爸您好，关于课程有效期我跟您说明一下。您购买的[X课时]套餐，有效期是从开课日起[X个月]，也就是说到[具体日期]截止。在这个有效期内，XX可以灵活安排上课频率。如果因为特殊情况（如生病、休学）导致课时没上完，可以在到期前[X天]申请延期[X个月]。如果确实过期了，未使用的课时[说明处理方式，如按一定比例折算/需要续费激活]。建议您合理安排上课频率，目前XX的课时消耗进度是[正常/偏慢/偏快]。我帮您看一下具体的有效期和剩余情况[发送详细信息]。"

## Q10: 续费后可以换老师/换科目吗？

**分类：** 续费类
**适用场景：** 家长在续费前确认是否可以调整老师或科目
**标准回复要点：**
1. 说明续费后调整老师/科目的政策
2. 解释调整的流程和条件
3. 告知调整可能涉及的费用变化
4. 引导家长在续费前就沟通好需求
5. 表达会尽力满足孩子的需求
6. 避免让家长感到被锁定

**话术模板：**
"XX妈妈您好，续费后当然是可以调整的。关于换老师：如果您对目前的教学有任何不满意的地方，可以随时跟我沟通，我会帮您协调。换老师的话一般需要提前[X周]申请，我们会根据XX的水平匹配合适的老师。关于换科目：如果XX想尝试其他科目，在课时有效期内是可以调整的，不同科目的课时单价可能不同，差价多退少补。不过我建议您在续费前就告诉我您的想法，这样我可以帮您一次性安排好，避免后续调整的麻烦。您目前有什么具体的调整想法吗？"

## Q11: 之前报的课还没上完，可以升级套餐吗？

**分类：** 续费类
**适用场景：** 家长想在当前套餐基础上升级或追加课时
**标准回复要点：**
1. 说明升级套餐的政策和流程
2. 告知剩余课时的处理方式（合并到新套餐）
3. 计算升级需要补的差价
4. 介绍升级后可以享受的额外服务
5. 对比升级前后的差异
6. 协助办理升级手续

**话术模板：**
"XX爸爸您好，可以升级的！您目前的[基础套餐]还有[X课时]未使用，升级到[高级套餐]的话，剩余课时会按[X方式，如按比例折算/全额转入]合并到新套餐中。升级需要补的差价是[X元]，升级后XX可以享受[列出额外服务，如一对一辅导/专属学习顾问等]。从性价比来看，升级后每课时单价从[X元]降到了[X元]，更划算。如果您决定升级，我这边帮您提交申请，[X个工作日]内就生效了。您要不要考虑一下？"

## Q12: 续费和首次报名的价格一样吗？老学员有什么特权？

**分类：** 续费类
**适用场景：** 家长询问老学员续费是否有特殊优惠
**标准回复要点：**
1. 强调老学员的专属权益
2. 对比老学员和新学员的价格差异
3. 介绍老学员专属的服务和福利
4. 说明老学员续费的优惠力度
5. 表达对老学员的重视和感谢
6. 引导家长感受续费的价值

**话术模板：**
"XX妈妈您好，老学员续费当然是有特权的！首先价格上，老学员续费可以享受[X折优惠]，比新学员便宜[X元/X%]。其次，老学员还可以享受以下专属福利：一是[福利1，如优先选课/优先选老师]，二是[福利2，如免费参加特定讲座/活动]，三是[福利3，如生日当月赠送课时]。另外，续费时还可以叠加使用[其他优惠，如老带新优惠/多科联报优惠]。我们对老学员一直是很重视的，感谢您一直以来的信任和陪伴。我帮您把老学员续费的专属方案发给您看看。"
