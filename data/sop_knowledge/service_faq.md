# 服务类常见问题SOP

> 本文档适用于教育培训机构"二讲老师"在家长答疑场景下的服务类问题标准回复参考。二讲老师需根据实际情况灵活调整话术，保持专业、真诚、有温度的沟通风格。

---

## Q1: 孩子今天不能来上课，怎么请假？

**分类：** 服务类
**适用场景：** 家长需要为孩子请假，咨询请假流程
**标准回复要点：**
1. 热情回应，表示理解
2. 说明请假的具体流程（微信/电话/APP操作）
3. 告知请假的截止时间要求
4. 说明请假后的补课安排
5. 提醒家长关注后续课程安排
6. 表达关心（如孩子身体不舒服，适当问候）

**话术模板：**
"XX妈妈您好，没问题，我帮您登记请假。您可以直接在[APP/微信群]里操作，也可以告诉我，我帮您在系统里登记。请假的话建议尽量提前[X小时]告知，这样我们好安排补课。关于这节课的内容，我会把课堂重点和作业发给您，XX在家可以先看一下。补课的话可以安排在[具体时间/方式]，到时我再跟您确认。另外，XX是身体不舒服吗？希望孩子早点好起来，有什么需要随时跟我说。"

## Q2: 想调整上课时间，怎么办理？

**分类：** 服务类
**适用场景：** 家长因时间冲突需要调整上课时间
**标准回复要点：**
1. 了解调课的具体需求（调整到什么时间、是临时还是长期）
2. 查看可用的调课时段
3. 说明调课的规则和限制（如提前多久申请、每期可调几次）
4. 提供可选的替代时段
5. 确认调课后的安排
6. 提醒家长调课生效后的注意事项

**话术模板：**
"XX爸爸您好，调课没问题的。我先了解一下，您是想把[具体时间]的课调到什么时候呢？是偶尔调整还是长期都需要改时间？[了解需求]好的，我帮您看一下可选的时段。目前[列出2-3个可选时段]是有位置的，您看哪个时间比较合适？另外跟您说一下，调课的话建议提前[X天]申请，每学期一般可以调[X]次。确认好时间后我帮您在系统里改过来，调课成功后您会在[APP/微信]收到通知。"

## Q3: 新学期的教材什么时候可以领？

**分类：** 服务类
**适用场景：** 家长咨询教材领取的时间和方式
**标准回复要点：**
1. 告知教材预计到达时间
2. 说明领取方式（前台领取/邮寄/课堂发放）
3. 如果需要家长领取，告知具体地点和营业时间
4. 说明是否需要携带凭证（学员卡、收据等）
5. 提及电子版资料的获取方式
6. 如有延迟，提前告知并致歉

**话术模板：**
"XX妈妈您好，新学期的教材预计在[X月X日]左右到位。到时候您有两个方式可以领取：一是到校区前台领取，我们的地址是[具体地址]，营业时间是[具体时间]；二是如果方便的话，上课时我会直接带给孩子。领取的时候需要您出示一下[学员卡/报名确认信息]。另外，电子版的预习资料我已经发到[微信群/APP]里了，XX可以先看起来，不用等纸质教材。如果教材到货有延迟，我会第一时间通知您。"

## Q4: 上课地点在哪里？怎么过去方便？

**分类：** 服务类
**适用场景：** 新学员家长或需要更换校区的家长咨询上课地点
**标准回复要点：**
1. 提供详细的校区地址
2. 给出交通指引（地铁/公交/自驾/停车信息）
3. 说明校区所在楼层和入口
4. 提供校区的联系电话
5. 如有照片或地图，一并发送
6. 询问是否需要其他帮助

**话术模板：**
"XX妈妈您好，我们[XX校区]的地址是[详细地址]。交通方面给您几个参考：地铁可以坐[X号线]到[XX站]，从[X出口]出来步行约[X]分钟；公交可以坐[X路]到[XX站]下车；如果自驾的话，校区附近有[停车场信息]，一般[收费情况]。到了之后请到[X楼/X号门]，前台会有老师接待。我把校区的定位发给您[发送定位/照片]。如果当天找不到路，可以随时拨打校区电话[电话号码]。还有什么需要了解的随时问我。"

## Q5: 课后有问题可以问老师吗？怎么答疑？

**分类：** 服务类
**适用场景：** 家长咨询课后答疑的渠道和时间安排
**标准回复要点：**
1. 明确告知课后答疑的渠道和方式
2. 说明答疑的时间安排
3. 解释答疑的响应时效
4. 引导家长正确使用答疑服务
5. 说明哪些问题适合课后答疑，哪些需要课堂解决
6. 鼓励家长和孩子主动提问

**话术模板：**
"XX爸爸您好，课后答疑当然可以的，这是我们服务的重要部分。目前我们有几个答疑渠道：一是微信群答疑，您或XX有任何问题随时发在群里，我会在[X小时内]回复；二是每周[X]晚上[X点-X点]有固定的在线答疑时间，我会实时在线解答；三是如果问题比较复杂，可以提前跟我预约，我安排一次一对一的语音/视频答疑。建议您鼓励XX自己来问问题，这样对孩子的学习更有帮助。另外，如果是课堂内容相关的问题，也可以让孩子在课堂上直接问我，我随时欢迎。"

**适用场景：** 家长需要查看课程安排和时间表
**标准回复要点：**

## Q7: 寒暑假课程是怎么安排的？

**分类：** 服务类
**适用场景：** 家长咨询假期课程安排和报名方式
**标准回复要点：**
1. 说明假期课程的总体安排（起止时间、总课时）
2. 介绍假期课程的特色和与平时的区别
3. 提供不同班型的选择（集训班/常规班/兴趣班等）
4. 说明报名时间和优惠信息
5. 提醒假期课程的考勤和请假规则
6. 主动推荐适合孩子水平的班型

**话术模板：**
"XX妈妈您好，[寒/暑]假的课程安排已经出来了，我给您介绍一下。今年的假期课程从[X月X日]到[X月X日]，共[X周]，每周[X]节课。假期课程的特点是[描述特色，如集中强化、专题突破等]。我们准备了几个班型：[班型1，适合XX水平的孩子]、[班型2，适合XX水平的孩子]。根据XX目前的学习情况，我推荐[具体班型]，因为[推荐理由]。报名截止日期是[X月X日]，早鸟报名的话可以享受[优惠信息]。您要不要先看一下课程大纲？我发给您。"

## Q8: 孩子想转到其他班级，怎么办理？

**分类：** 服务类
**适用场景：** 家长或孩子提出转班需求
**标准回复要点：**
1. 了解转班的原因和期望
2. 评估转班的可行性（目标班级是否有名额、水平是否匹配）
3. 说明转班的流程和所需时间
4. 告知转班可能涉及的费用调整
5. 提出过渡期安排
6. 跟进转班后的适应情况

**话术模板：**
"XX爸爸您好，转班的事情我来帮您处理。先了解一下，XX想转到哪个班级呢？转班的主要原因是什么？[了解需求]好的，我帮您查一下。目前[目标班级]还有[X]个名额，班级水平是[描述]，和XX目前的情况[匹配情况]。如果确认要转的话，流程是这样的：我这边先提交转班申请，教务老师会在[X个工作日]内审核，审核通过后[具体生效时间]就可以到新班级上课了。转班期间XX可以先在原班级上课，不影响学习进度。费用方面[说明费用情况]。转班后我也会关注XX的适应情况，您放心。"

## Q9: 孩子缺了课怎么补？有补课安排吗？

**分类：** 服务类
**适用场景：** 家长咨询缺课后的补课政策和安排
**标准回复要点：**
1. 说明补课政策和规则（每期可补几次、补课期限等）
2. 了解缺课的原因和缺课数量
3. 提供补课的具体方式（跟其他班补/线上补课/一对一补课）
4. 列出可选的补课时间
5. 说明补课的预约流程
6. 提醒补课的时效要求

**话术模板：**
"XX妈妈您好，关于补课安排我跟您说明一下。我们每学期有[X]次免费补课名额，需要在缺课后的[X周]内完成补课。XX目前缺了[X]次课，补课有几种方式：一是跟其他同进度的班级补，目前可选的时间有[列出时间]；二是如果时间不合适，可以安排线上补课，我通过视频给XX单独讲；三是如果缺课较多，也可以安排一次集中补课。您看哪种方式比较方便？确定后我帮您预约。另外，缺课期间的课堂笔记和作业我已经整理好了，可以先发给您让孩子预习。"

## Q10: 家长可以旁听课程吗？

**分类：** 服务类
**适用场景：** 家长咨询是否可以进入课堂旁听
**标准回复要点：**
1. 说明旁听政策（是否允许、频率限制等）
2. 解释旁听的规则和注意事项
3. 建议合适的旁听方式（如开放日、家长观摩课）
4. 引导家长理解频繁旁听可能影响孩子
5. 提供替代方案（课后反馈、课堂录像等）
6. 表达对家长关注孩子学习的理解

**话术模板：**
"XX爸爸您好，感谢您对XX学习的关注。关于旁听，我们的政策是这样的：每学期我们有[X]次家长开放日/观摩课，家长可以在这些时间来旁听。另外，如果平时有旁听需求，需要提前[X天]跟我申请，校区同意后就可以来。不过我想跟您分享一个小建议：有些孩子在家长旁听时反而会紧张，表现不如平时自然。如果您想了解XX的课堂表现，我可以在每次课后给您发一份简短的课堂反馈，包括XX的参与度、掌握情况等，这样您也能及时了解。您觉得怎么样？"

## Q11: 孩子上课需要带什么？有什么准备吗？

**分类：** 服务类
**适用场景：** 新学员家长或新学期开始前咨询课前准备
**标准回复要点：**
1. 列出需要携带的物品清单
2. 说明教材和资料的领取方式
3. 提及课前预习的建议
4. 说明电子设备的使用要求
5. 提醒上课的着装和饮食建议
6. 主动发送课前准备清单

**话术模板：**
"XX妈妈您好，上课需要准备的东西我给您列一下：一是教材和练习册（如果还没领的话，上课时我会发给孩子）；二是文具（铅笔、橡皮、笔记本等）；三是如果涉及线上互动环节，可以带一个平板或手机。不需要带的东西：零食和玩具请不要带进教室。课前建议XX提前[X分钟]到，可以做好上课准备。另外，建议课前[X分钟]让孩子简单预习一下当天要学的内容，效果会更好。我把完整的准备清单发给您[发送清单]，有什么不清楚的随时问我。"

## Q12: 孩子上课迟到/早退怎么办？

**分类：** 服务类
**适用场景：** 家长咨询迟到早退的处理方式和影响
**标准回复要点：**
1. 说明迟到/早退的登记方式
2. 告知迟到/早退对学习的影响（客观说明，不指责）
3. 说明缺课部分的补课安排
4. 提醒考勤规则（如累计迟到次数的影响）
5. 给出避免迟到早退的建议
6. 表达理解，不施加过大压力

**话术模板：**
"XX爸爸您好，如果XX需要迟到或早退，请尽量提前告诉我，这样我好安排。迟到的话，XX来了之后我会尽快帮孩子跟上进度，课后也会把错过的内容补上。早退的话，我会把当堂的重点内容整理发给您，XX在家可以看一下。不过想跟您说一下，经常迟到的话确实会影响学习效果，因为课程开头通常是[描述，如知识点讲解/重点梳理]，错过了后面会吃力。建议您尽量让XX准时到校，如果确实有特殊情况，提前沟通就好，我们一起想办法。"
